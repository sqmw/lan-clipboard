# Security

## 威胁模型（局域网默认不可信）

同网段可能存在：
- 嗅探/中间人
- 恶意设备伪装成“同名设备”
- 大包/畸形数据导致资源耗尽

因此默认需要：
- 共享码建立共享域级信任（后续升级设备指纹）
- 传输加密（控制帧为 `AES-GCM-SIV`，文件体为 `ChaCha20-Poly1305`）
- 严格大小限制与解析前校验

## 共享码与加密（M0 当前实现）

当前流程：
1) 共享域内所有设备设置同一 `shared_code`
2) 应用通过 `mDNS` 与 UDP 心跳持续广播自己，只接纳 `shared_code` 相同的设备
3) 同步消息直接使用 `shared_code` 派生密钥
4) `shared_code` 不一致时会解密失败并记录错误日志
5) 启用加密传输会额外消耗 CPU，实际吞吐会明显下降；如果只在可信局域网内使用且更关注速度，可以关闭加密换取更高传输速度

## 传输（当前 + 后续）

当前：`TCP + AES-GCM-SIV` 控制帧 + `ChaCha20-Poly1305` 文件体帧
后续：`TCP + TLS` 或 `QUIC + Noise/TLS`
