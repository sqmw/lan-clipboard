# Security

## 威胁模型（局域网默认不可信）

同网段可能存在：
- 嗅探/中间人
- 恶意设备伪装成“同名设备”
- 大包/畸形数据导致资源耗尽

因此默认需要：
- 配对后建立信任（当前为共享配对码，后续升级设备指纹）
- 传输加密（当前为 `AES-GCM-SIV`）
- 严格大小限制与解析前校验

## 配对（M0 当前实现）

当前流程：
1) 设备发现（mDNS）展示候选
2) 用户在 A/B 两端设置同一配对码
3) 若开启“强制配对码”，空配对码将禁止同步启动
4) 同步消息使用配对码派生密钥加密，配对码不一致时会解密失败并记录错误日志

## 传输（当前 + 后续）

当前：`TCP + AES-GCM-SIV`
后续：`TCP + TLS` 或 `QUIC + Noise/TLS`
