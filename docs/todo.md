## 风险清单（需要早决策）

- “任何类型”跨 OS 的真实含义：macOS UTI 与 Windows clipboard formats 不可一一映射；建议定义“跨平台支持的格式集合”，其余类型降级或跳过（详见 `docs/protocol.md`）。

- Windows `RTF` 当前仍保留兼容读取路径；若后续发现慢或不稳定，应继续切到原生注册格式读取。
