# LAN Clipboard (Tauri)

同一局域网内的 macOS / Windows 设备共享剪贴板（Tauri UI + Rust Core）。

当前状态（2026-05-16）：
- 已支持 Win / macOS 双端在同一局域网内同步剪贴板（已实现文本/图片的基础路径）
- 已支持大小限制配置落盘、同步开关与运行状态
- 已支持手动扫描设备 + 设备码连接（mDNS）
- 已支持配对码驱动的加密传输（AES-GCM-SIV）

## 目标与边界

- 目标：共享剪贴板（优先常用格式），可配置大小限制
- 安全：局域网默认不可信，配对后建立信任并加密传输（详见 `docs/security.md`）
- “任何类型”：跨 OS 不承诺“任意格式完全等价”，以“跨平台支持的格式集合”为承诺边界（详见 `docs/protocol.md`）

## 开发

- 安装：`pnpm install`
- 运行：`pnpm tauri dev`

## 双端快速联调（Win + macOS）

1. 两台机器连接同一局域网并启动应用。
2. 点击“手动扫描设备”，在列表里把对端加入 peers（或在高级里手动填写 IP）。
4. 两端都开启“启用加密传输”，并设置一致的“配对码”（建议开启“强制配对码”）。
5. 点击“保存配置”，然后点击“开始同步”。
6. 在任一端复制文本或图片，另一端应在 1 秒左右更新剪贴板。
